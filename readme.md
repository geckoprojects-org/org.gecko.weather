# Gecko Weather

This project implements a basic Deutscher Wetter Dienst API that includes

* Weather API
* Weather Model
* Stations
* Weather Forecast
* Astrotime Time4J

The Weather API documentation is located in the [org.gecko.weather.api](org.gecko.weather.api/README.MD). The weather model is located in the *prg.gecko.weather.model* project.

The station service documentation is located in the [org.gecko.weather.dwd.stations](org.gecko.weather.dwd.stations/README.MD).

The forecast service documentation is located in the [org.gecko.weather.dwd.forecast](org.gecko.weather.dwd.forecast/README.MD).

The Time4J Astrotime Documentation is located in the [org.gecko.time4j](org.gecko.time4j/README.MD).
